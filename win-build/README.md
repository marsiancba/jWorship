# jWorship Windows Build

To get the Windows executable:

1. Combine the parts:
   - **Windows (PowerShell):** `cmd /c copy /b jworship_part_aa+jworship_part_ab+jworship_part_ac jWorship-4.2.1-win.zip`
   - **Linux/Mac:** `cat jworship_part_* > jWorship-4.2.1-win.zip`
2. Extract the zip
3. Run `jWorship.exe`
